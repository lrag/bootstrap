1. ¿Qué es un contenedor?

El contenedor es el elemento de maquetación más básico de Bootstrap: una caja que envuelve el contenido, lo centra horizontalmente, le da un ancho máximo según el tamaño de pantalla y le añade un relleno lateral para que el texto no toque los bordes. 

<body>
  <div class="container">
    <!-- todo el contenido aquí -->
  </div>
</body>
  • Centrado: margin-left: auto; margin-right: auto.
  • Ancho máximo: max-width distinto en cada breakpoint.
  • Relleno lateral: 0.75rem por lado (la mitad del gutter de 1.5rem).
  • Imprescindible para la rejilla: las .row tienen márgenes negativos que el relleno del contenedor compensa.
Los contenedores se pueden anidar, pero casi nunca hace falta. Lo habitual es uno por sección (cabecera, contenido, pie) o uno solo para toda la página.

2. Los seis breakpoints

Un breakpoint (punto de ruptura) es un ancho de viewport a partir del cual el diseño puede cambiar. Bootstrap 5 define seis, y cada uno tiene un infijo que aparece en el nombre de las clases (col-md-6, d-lg-none, container-xl…).

xs no tiene infijo. No existe col-xs-6 (sí existía en Bootstrap 3). Una clase sin infijo, como col-6, se aplica desde 0 px.
xxl es nuevo en Bootstrap 5. Bootstrap 4 solo llegaba hasta xl (1200 px).

Los breakpoints se definen en Sass (mapa $grid-breakpoints), así que se pueden cambiar al compilar Bootstrap. Desde la 5.3 también están expuestos como variables CSS --bs-breakpoint-md, etc., aunque solo como información: las variables CSS no funcionan dentro de una media query.

3. Tipos de contenedor

.container

Ancho fijo que salta en cada breakpoint. Al 100 % solo en móvil (xs). El más habitual.

.container-fluid

Siempre al 100 % del ancho. Para paneles, dashboards o bandas a ancho completo.

.container-{breakpoint}

Al 100 % hasta ese breakpoint; a partir de él se comporta como .container.

5. El enfoque mobile-first

Bootstrap se diseña primero para el móvil y luego se va ampliando para pantallas mayores. Técnicamente significa que sus media queries usan min-width: una clase con infijo se aplica desde ese breakpoint hacia arriba, nunca hacia abajo.

Lo que hace Bootstrap por dentro (simplificado):

/* Sin infijo: desde 0 px (móvil) */
.text-center { text-align: center; }

/* md: desde 768 px hacia arriba */
@media (min-width: 768px) {
  .text-md-start { text-align: left; }
}

Cómo se usa en el HTML:

<p class="text-center text-md-start">
  Centrado en móvil, a la izquierda desde tablet
</p>

<div class="col-12 col-md-6 col-xl-4">
  Ancho completo → mitad → tercio
</div>

Cómo se lee una lista de clases responsive

  1. La clase sin infijo es el estilo base: el del móvil.
  2. Cada clase con infijo sobrescribe la anterior a partir de su breakpoint.
  3. Si un breakpoint no tiene clase, hereda la del breakpoint inferior más cercano.

Ejemplo en vivo:

text-center text-md-start text-xl-end → centrado en móvil, izquierda desde md, derecha desde xl.

Por qué mobile-first: el móvil es la pantalla más limitada y hoy la más usada. Partir de lo sencillo y añadir complejidad es más fácil que recortar un diseño de escritorio.
¿Y hacia abajo? En Sass existe media-breakpoint-down(md), que genera max-width: 767.98px. Los .98 evitan que dos media queries coincidan en el mismo píxel.

6. Práctica

Contenedores y breakpoints

  1. Crear una página con tres bloques: cabecera con .container-fluid, contenido con .container y pie con .container-lg, cada uno con un color de fondo distinto.
  2. Redimensionar la ventana y anotar en qué anchos cambia cada bloque.
  3. Añadir un título con text-center text-lg-start y comprobar en qué breakpoint cambia la alineación.
  4. Mostrar un mensaje solo en móvil con d-md-none y otro solo desde tablet con d-none d-md-block.

1. ¿Qué es Bootstrap?

Bootstrap es un framework de front-end de código abierto, creado en Twitter en 2011, que reúne CSS y JavaScript listos para usar. Permite maquetar interfaces responsive y coherentes aplicando clases en el HTML, sin escribir apenas CSS propio.

Rejilla

Sistema de 12 columnas basado en flexbox con seis breakpoints, pensado mobile-first.

Utilidades

Clases de una sola responsabilidad: espaciado, color, flex, bordes, sombras, visibilidad…

Componentes

Navbar, cards, modales, formularios, carrusel… con estilos y comportamiento incluidos.

Personalización

Variables CSS --bs-* y código fuente en Sass para adaptarlo a cualquier marca.

2. Qué cambia respecto a Bootstrap 4

Aspecto Bootstrap 4 Bootstrap 5.3
jQuery Obligatorio para los componentes JS Eliminado JavaScript nativo
Breakpoints 5 (xs, sm, md, lg, xl) 6: se añade xxl (≥ 1400 px)
Utilidades Conjunto fijo Ampliadas y extensibles con la API de utilidades
Personalización Solo con Sass Variables CSS --bs-* además de Sass
Modos de color No Claro y oscuro con data-bs-theme
RTL No Soporte para idiomas de derecha a izquierda
Atributos data data-toggle data-bs-toggle (prefijo bs)
Internet Explorer IE 10 y 11 Sin soporte

3. Instalación

Opción A · CDN

La más rápida: no requiere instalar nada. Ideal para prototipos y para empezar el curso.

En el <head>:

<link href="https://cdn.jsdelivr.net/npm/bootstrap@5.3.8/dist/css/bootstrap.min.css"
      rel="stylesheet">

Al final del <body> (incluye Popper):

<script src="https://cdn.jsdelivr.net/npm/bootstrap@5.3.8/dist/js/bootstrap.bundle.min.js"></script>
Opción B · npm

Para proyectos reales: control de versiones, Sass y compilación propia (lo veremos en la personalización).

npm init -y
npm install bootstrap@5.3

Los ficheros quedan en node_modules/bootstrap/:

  • dist/css/bootstrap.min.css → CSS compilado
  • dist/js/bootstrap.bundle.min.js → JS con Popper
  • scss/ → código fuente Sass
¿bundle o no bundle? bootstrap.bundle.min.js incluye Popper, necesario para dropdowns, tooltips y popovers. bootstrap.min.js no lo incluye y tendrías que cargarlo aparte.

4. Estructura de una plantilla base

<!doctype html>
<html lang="es" data-bs-theme="light">
<head>
  <meta charset="utf-8">
  <meta name="viewport" content="width=device-width, initial-scale=1">
  <title>Mi primera página con Bootstrap</title>
  <link href="https://cdn.jsdelivr.net/npm/bootstrap@5.3.8/dist/css/bootstrap.min.css"
        rel="stylesheet">
</head>
<body>
  <div class="container">
    <h1>¡Hola, Bootstrap!</h1>
  </div>

  <script src="https://cdn.jsdelivr.net/npm/bootstrap@5.3.8/dist/js/bootstrap.bundle.min.js"></script>
</body>
</html>
  1. <!doctype html>: activa el modo estándar del navegador. Sin él, Bootstrap se ve mal.
  2. lang: idioma del documento, importante para accesibilidad y lectores de pantalla.
  3. data-bs-theme: modo de color de toda la página (light o dark).
  4. Meta viewport: imprescindible para que el diseño responsive funcione en móviles.
  5. CSS en el <head>: evita que la página se pinte sin estilos.
  6. JS al final del <body>: no bloquea el pintado del contenido.

La meta viewport

Sin ella, los móviles simulan una pantalla de unos 980 px de ancho y reducen la página: los breakpoints nunca se activan y todo se ve diminuto. Con width=device-width el ancho de la página es el del dispositivo, y con initial-scale=1 no se aplica zoom inicial.

Prueba: abre esta página en las herramientas de desarrollo (F12 → modo dispositivo), borra la meta viewport y recarga. Observa cómo la rejilla deja de adaptarse.

5. Modos de color con data-bs-theme

Desde la versión 5.3, el atributo data-bs-theme cambia los colores de todos los componentes. Se puede poner en <html> para toda la página o en un elemento concreto para solo esa zona.

Toda la página

Cambia el atributo del elemento <html>:

Valor actual: light

Solo un elemento

Esta card tiene data-bs-theme="dark", así que siempre es oscura.

<div class="card" data-bs-theme="dark">…</div>

En el punto de modo claro y oscuro veremos cómo crear un selector de tema completo que recuerde la preferencia.

6. Práctica

Tu primera plantilla

  1. Crea una carpeta de proyecto y ábrela en VS Code.
  2. Crea un fichero index.html con la plantilla base del apartado 4.
  3. Ábrelo en el navegador y comprueba en F12 → Red que se cargan el CSS y el JS de Bootstrap.
  4. Añade un párrafo con la clase lead y un botón con class="btn btn-primary".
  5. Cambia data-bs-theme a dark y observa qué cambia.
  6. Opcional: instala Bootstrap con npm y enlaza los ficheros de node_modules en lugar del CDN.

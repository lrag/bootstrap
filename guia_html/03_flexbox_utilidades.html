1. Cómo se forma el nombre

Las utilidades de espaciado son clases que aplican una sola propiedad CSS: un margen o un relleno. El nombre tiene tres partes, siempre en este orden: qué, dónde y cuánto.

Todos los valores van en rem: si cambia el tamaño de letra base del navegador, el espaciado crece en proporción al texto. x e y son los ejes de una gráfica: x el horizontal, y el vertical.

Bootstrap declara estas utilidades con !important, para que ganen siempre a cualquier otra regla.
En Bootstrap 4 los lados eran l y r: pl-3, ml-auto. En Bootstrap 5 son ps-3, ms-auto.

5. Margin auto

Con un ancho fijo, el margen automático reparte el espacio sobrante:

  • Sin auto: la caja se queda a la izquierda y el espacio sobrante queda a su derecha.
  • margin-right: auto: todo el margen a la derecha, así que la caja queda igual, a la izquierda.
  • mx-auto: el mismo margen a los dos lados, así que la caja queda centrada.
  • ms-auto: todo el margen a la izquierda, así que la caja se va a la derecha.

6. Start y end: por qué no se llaman left y right

s y e no significan izquierda y derecha, sino donde empieza y donde acaba el texto. En español empieza a la izquierda, pero en árabe, hebreo, persa o urdu se escribe de derecha a izquierda y empieza a la derecha.

El atributo dir

<html lang="ar" dir="rtl">

Se hereda: puede ponerse en <html> o en un único elemento. Con dir="auto" el navegador decide según el primer carácter del texto.

El navegador ordena solo las letras dentro de una palabra, pero sin dir="rtl":

  • el texto queda alineado a la izquierda;
  • los elementos de una línea se colocan de izquierda a derecha;
  • start y end siguen significando izquierda y derecha.

Propiedades lógicas de CSS

Dicen «al principio» o «al final»; el navegador las traduce a un lado según el dir.

Propiedad lógicadir="ltr"dir="rtl"
margin-inline-startmargin-leftmargin-right
margin-inline-endmargin-rightmargin-left
padding-inline-startpadding-leftpadding-right
padding-inline-endpadding-rightpadding-left

Ejemplo: un botón con una lupa

Queremos separación entre la lupa y el texto, así que la lupa lleva un margen al final. En árabe la lupa aparece siempre a la derecha, porque ahí empieza el texto: lo que hay que mirar es el hueco. Si la lupa se pega al texto, el margen se ha ido al lado de fuera. (بحث significa «buscar».)

La última fila «parece» correcta, pero es una chapuza: cambiamos el orden del HTML para imitar el resultado. El texto sigue alineado a la izquierda y el diseño deja de servir en cuanto el idioma cambia. La solución es dir="rtl" más propiedades lógicas o la hoja RTL de Bootstrap.

Las dos hojas de estilos de Bootstrap

me-3 no se adapta sola porque Bootstrap no usa propiedades lógicas en sus utilidades. Trae dos hojas de estilos con los mismos nombres de clase y los lados invertidos:

FicheroRegla
bootstrap.min.css.me-3 { margin-right: 1rem !important; }
bootstrap.rtl.min.css.me-3 { margin-left: 1rem !important; }
Una web de derecha a izquierda con Bootstrap necesita las dos cosas: dir="rtl" en <html> para el navegador y bootstrap.rtl.min.css para las clases. El HTML no cambia; por eso las clases se llaman start y end.

7. Espaciado responsive

Como en los contenedores, se puede añadir un breakpoint en medio del nombre: {qué}{dónde}-{breakpoint}-{cuánto}. Es mobile-first: p-2 p-md-5 aplica p-2 en móvil y, a partir de md (768 px), p-5. 

<div class="p-2 p-md-5">…</div>

8. Flexbox: contenedor, ejes y dirección

Flexbox es CSS puro: coloca elementos en fila o en columna, reparte el espacio entre ellos y los alinea. Bootstrap solo le pone clases. La propia rejilla está hecha con flexbox: .row es un contenedor flex.

Dos niveles

  • Contenedor flex: el elemento con d-flex (display: flex).
  • Elementos flex: sus hijos directos, que pasan a colocarse en fila.

Dos ejes

  • Principal: la dirección en la que se colocan (en fila, el horizontal). Lo controla justify-content.
  • Cruzado: el perpendicular (en fila, el vertical). Lo controla align-items.

11. Hueco y salto de línea: gap-* y flex-wrap

gap-* separa los elementos entre sí, pero no de los bordes del contenedor. Usa la escala del espaciado (gap-3 = 1rem) y es mejor que poner margen a cada elemento: no deja hueco sobrante al final. También existen row-gap-* y column-gap-*.

Por defecto (flex-nowrap) todos los elementos se quedan en la misma línea aunque no quepan. Con flex-wrap los que no caben bajan a la siguiente. .row lleva flex-wrap: por eso las columnas que no caben bajan de línea.

17. Visibilidad responsive: d-*

Para mostrar u ocultar elementos según el ancho de pantalla se usan las utilidades de display (la d viene de display). Siguen el patrón de siempre, mobile-first: 

d-{valor}                → en todos los anchos
d-{breakpoint}-{valor}   → a partir de ese breakpoint
BootstrapCSS
d-nonedisplay: none: el elemento desaparece por completo
d-block / d-inline / d-inline-blockdisplay: block / inline / inline-block
d-flex / d-inline-flex / d-griddisplay: flex / inline-flex / grid
d-md-none, d-lg-block…Lo mismo dentro de @media (min-width: …)
No hay clases «ocultar en móvil» ni «mostrar en escritorio». Siempre se combinan dos: una para el punto de partida y otra para el cambio. Se leen de izquierda a derecha: d-none d-md-block es «oculto; a partir de md, visible».

El indicador de breakpoint

Seis etiquetas, una por breakpoint. Cada una está oculta y solo se muestra en su tramo; por ejemplo, la de md lleva d-none d-md-inline d-lg-none. En cada ancho solo queda visible una, sin JavaScript. Es el mismo indicador que hay fijo abajo a la derecha de esta página.

Solo para lectores de pantalla: visually-hidden

d-none oculta el elemento para todo el mundo, también para los lectores de pantalla que usan las personas ciegas. visually-hidden lo oculta solo a la vista: el lector lo sigue leyendo. Caso típico: un botón que solo muestra un icono necesita un texto que diga qué hace. Se verá más a fondo en accesibilidad.

botón con 🔍 y «Buscar» en visually-hidden

<button type="button" class="btn btn-outline-secondary">
  🔍<span class="visually-hidden">Buscar</span>
</button>

Al imprimir: d-print-*

Las mismas clases con print en lugar de un breakpoint se aplican solo al imprimir: d-print-none no sale en papel (menús, botones, publicidad…) y d-none d-print-block solo sale en papel. Se comprueba con Ctrl+P y la vista previa de impresión.

Este bloque no sale al imprimir (d-print-none)
Este bloque solo sale al imprimir (d-none d-print-block)
<nav class="d-print-none">…</nav>
<p class="d-none d-print-block">Impreso desde www.mi-web.es</p>

18. Práctica

Ejercicio

  1. Crear una caja con un título y un párrafo, y darle relleno con p-* hasta que el texto respire.
  2. Separar varias cajas seguidas con mb-* en lugar de <br>.
  3. Centrar una caja de 300 px de ancho con mx-auto.
  4. Hacer que el relleno sea pequeño en móvil y grande desde lg.
  5. Maquetar una barra con un logo a la izquierda y tres enlaces a la derecha usando d-flex y ms-auto.
  6. Rehacerla con justify-content-between y comparar.
  7. Centrar un texto en una caja de 300 px de alto en las dos direcciones.
  8. Hacer que la barra pase a columna en móvil con flex-column flex-md-row.
  9. Convertir una de las cajas en una tarjeta con border, rounded-3 y shadow.
  10. Hacer una portada a pantalla completa con min-vh-100 y el texto centrado.
  11. En la barra, mostrar los enlaces solo desde md y un botón «Menú» solo por debajo de md.
  12. Escribir el CSS normal equivalente de cada clase usada.

1. Qué hace el JavaScript de Bootstrap

Casi todo Bootstrap es CSS: la rejilla, las utilidades, las cards o los formularios funcionan sin JavaScript. El JavaScript solo hace falta para los componentes que reaccionan a lo que hace el usuario. Desde la versión 5 es JavaScript normal: no necesita jQuery.

ComponenteQué hace con JavaScript¿Necesita Popper?
AlertCerrar la alertaNo
ButtonEstado pulsado / no pulsadoNo
CarouselPasar las diapositivasNo
CollapseMostrar y ocultar un bloque (acordeón, menú de la navbar)No
DropdownAbrir el menú desplegableSí
ModalVentana modalNo
OffcanvasPanel lateralNo
PopoverGlobo con título y contenidoSí
ScrollSpyMarcar en el menú la sección visibleNo
TabPestañasNo
ToastNotificacionesNo
TooltipTexto flotante al pasar el ratónSí

Hay dos formas de usarlo: con atributos data-bs-* en el HTML, sin escribir nada de JavaScript, o con la API programática desde nuestro código.

2. El bundle y Popper

Popper es una librería que calcula dónde colocar un elemento flotante respecto a otro: que no se salga de la pantalla, que se dé la vuelta si no cabe debajo… La usan los dropdowns, los tooltips y los popovers.

FicheroContieneCuándo
bootstrap.bundle.min.jsBootstrap + PopperLo normal: un solo fichero y funciona todo
bootstrap.min.jsSolo BootstrapSi Popper ya se carga por otro lado (o no se usan dropdowns, tooltips ni popovers)

Con el bundle

<script src="https://cdn.jsdelivr.net/npm/bootstrap@5.3.8/dist/js/bootstrap.bundle.min.js" defer></script>

Sin el bundle: Popper primero

<script src="https://cdn.jsdelivr.net/npm/@popperjs/core@2.11.8/dist/umd/popper.min.js" defer></script>
<script src="https://cdn.jsdelivr.net/npm/bootstrap@5.3.8/dist/js/bootstrap.min.js" defer></script>
El bundle crea un objeto global, bootstrap, con una clase por componente: bootstrap.Collapse, bootstrap.Modal, bootstrap.Tooltip… Es lo que usa la API programática.

3. Sin escribir JavaScript: atributos data-bs-*

Al cargar, Bootstrap se queda escuchando los clics de toda la página. Cuando se pulsa un elemento con data-bs-toggle, mira qué componente indica y sobre qué elemento actuar (data-bs-target, o el href en un enlace).

data-bs-toggle="collapse" data-bs-target="#detalles"

Envío en 24 horas. Devoluciones gratis durante 30 días.
<button class="btn btn-primary" type="button"
        data-bs-toggle="collapse"
        data-bs-target="#detalles"
        aria-expanded="false" aria-controls="detalles">
  Condiciones de envío
</button>
<div class="collapse" id="detalles">…</div>
AtributoPara qué
data-bs-toggleEl componente que se activa: collapse, dropdown, modal, offcanvas, tab, button…
data-bs-targetEl elemento sobre el que actúa (selector CSS). En un enlace, vale el href
data-bs-dismissCierra el componente que contiene al botón: alert, modal, offcanvas, toast
data-bs-{opción}Una opción del componente (apartado siguiente)
En el inspector: al pulsar, Bootstrap pone o quita la clase show del bloque (con collapsing durante la animación) y cambia aria-expanded del botón entre false y true, para los lectores de pantalla.

4. Opciones

Cada componente tiene opciones (en la documentación, apartado Options). Se pueden dar de dos formas: como atributo data-bs- más el nombre de la opción, o como objeto en el constructor de JavaScript. Si el nombre tiene mayúsculas, en el atributo va con guiones: autoClose → data-bs-auto-close.

5. La API programática

Una instancia es el componente «vivo» de un elemento del HTML: guarda su estado y tiene los métodos para manejarlo. Se usa cuando la acción no sale de un clic en un botón: al terminar de guardar, al recibir datos del servidor, pasado un tiempo…

Para conseguir la instanciaQué hace
new bootstrap.Collapse(elemento, opciones)La crea
bootstrap.Collapse.getInstance(elemento)Devuelve la que ya exista, o null
bootstrap.Collapse.getOrCreateInstance(elemento, opciones)La que exista o una nueva: la más cómoda

El elemento puede ser el nodo del DOM o un selector CSS ('#panel'). Con data-bs-*, Bootstrap no crea la instancia al cargar, sino la primera vez que se usa: hasta entonces getInstance devuelve null.

MétodoQué hace
show() / hide() / toggle()Mostrar, ocultar, alternar (en casi todos los componentes)
dispose()Destruye la instancia y quita lo que Bootstrap había añadido al elemento
Propios de cada componenteclose() en Alert, next() y prev() en Carousel, enable() y disable() en Tooltip…

Tres botones sin data-bs-toggle

Un bloque manejado desde JavaScript.
const panel = bootstrap.Collapse.getOrCreateInstance(
  document.getElementById('panel'), { toggle: false })

document.getElementById('boton-mostrar').onclick = () => {
  panel.show()
}
{ toggle: false }: al crear la instancia de un collapse, por defecto se abre o se cierra en ese momento. Con esta opción, la instancia se crea sin tocar el bloque.

6. Componentes que hay que activar: tooltips y popovers

Por rendimiento, Bootstrap no busca tooltips ni popovers en la página: aunque tengan data-bs-toggle, no funcionan hasta que se crea su instancia con JavaScript. 

<button type="button" class="btn btn-secondary" id="ayuda"
        data-bs-title="Arriba" data-bs-placement="top">top</button>

new bootstrap.Tooltip(document.getElementById('ayuda'))
new bootstrap.Tooltip(otroBoton, { title: 'Abajo', placement: 'bottom' })

Los tooltips y los popovers se ven a fondo en el punto siguiente, con el resto de componentes interactivos.

7. Eventos

Los componentes lanzan eventos sobre su elemento con el nombre acción.bs.componente. Se escuchan con addEventListener (no existe onshow.bs.collapse: con puntos en el nombre no puede haber propiedad).

EventoCuándo¿Se puede cancelar?
show.bs.collapseVa a empezar a abrirseSí, con preventDefault()
shown.bs.collapseHa terminado de abrirse (después de la animación)No
hide.bs.collapseVa a empezar a cerrarseSí
hidden.bs.collapseHa terminado de cerrarseNo

El mismo patrón sirve para dropdown, modal, offcanvas, tab, toast y tooltip. Alert usa close y closed; carousel, slide y slid.

Registro de eventos

Un bloque que lanza eventos.

          

        

        


const bloque = document.getElementById('bloque')

bloque.addEventListener('show.bs.collapse', (evento) => {
  if (document.getElementById('bloquear').checked) {
    evento.preventDefault()
  }
})

bloque.addEventListener('shown.bs.collapse', () => {
  console.log('ya está abierto')
})

        

      

      

        ¿Por qué shown? Los métodos (show(), hide()…) vuelven enseguida, pero la animación sigue.
        Lo que tenga que pasar cuando el componente ya se ve (poner el foco en un campo de un modal, por ejemplo) va en shown.

1. Cómo se forma el nombre

Las utilidades de espaciado son clases que aplican una sola propiedad CSS: un margen o un relleno. El nombre tiene tres partes, siempre en este orden: qué, dónde y cuánto. 

{qué}{dónde}-{cuánto}        p  y  - 2   →   py-2

Qué

ppadding: relleno, por dentro del borde
mmargin: margen, por fuera del borde

Todos los valores van en rem: si cambia el tamaño de letra base del navegador, el espaciado crece en proporción al texto. x e y son los ejes de una gráfica: x el horizontal, y el vertical.

Bootstrap declara estas utilidades con !important, para que ganen siempre a cualquier otra regla.
En Bootstrap 4 los lados eran l y r: pl-3, ml-auto. En Bootstrap 5 son ps-3, ms-auto.

5. Margin auto

Con un ancho fijo, el margen automático reparte el espacio sobrante:

  • mx-auto: el mismo margen a los dos lados, así que la caja queda centrada.
  • ms-auto: todo el margen a la izquierda, así que la caja se va a la derecha.

class="mx-auto"

150 px centrado

margin-left: auto; margin-right: auto

150 px centrado

class="ms-auto"

150 px a la derecha

margin-left: auto

150 px a la derecha
Sin ancho, el margen automático no hace nada visible: un div ya ocupa todo el ancho y no sobra espacio que repartir.

6. Start y end: por qué no se llaman left y right

s y e no significan izquierda y derecha, sino donde empieza y donde acaba el texto. En español empieza a la izquierda, pero en árabe, hebreo, persa o urdu se escribe de derecha a izquierda y empieza a la derecha.

El atributo dir

<html lang="ar" dir="rtl">

Se hereda: puede ponerse en <html> o en un único elemento. Con dir="auto" el navegador decide según el primer carácter del texto.

El navegador ordena solo las letras dentro de una palabra, pero sin dir="rtl":

  • el texto queda alineado a la izquierda;
  • los elementos de una línea se colocan de izquierda a derecha;
  • start y end siguen significando izquierda y derecha.

Propiedades lógicas de CSS

Dicen «al principio» o «al final»; el navegador las traduce a un lado según el dir.

Propiedad lógicadir="ltr"dir="rtl"
margin-inline-startmargin-leftmargin-right
margin-inline-endmargin-rightmargin-left
padding-inline-startpadding-leftpadding-right
padding-inline-endpadding-rightpadding-left

Ejemplo: un botón con una lupa

Queremos separación entre la lupa y el texto, así que la lupa lleva un margen al final. En árabe la lupa aparece siempre a la derecha, porque ahí empieza el texto: lo que hay que mirar es el hueco. Si la lupa se pega al texto, el margen se ha ido al lado de fuera. (بحث significa «buscar».)

Las dos hojas de estilos de Bootstrap

me-3 no se adapta sola porque Bootstrap no usa propiedades lógicas en sus utilidades. Trae dos hojas de estilos con los mismos nombres de clase y los lados invertidos:

FicheroRegla
bootstrap.min.css.me-3 { margin-right: 1rem !important; }
bootstrap.rtl.min.css.me-3 { margin-left: 1rem !important; }
Una web de derecha a izquierda con Bootstrap necesita las dos cosas: dir="rtl" en <html> para el navegador y bootstrap.rtl.min.css para las clases. El HTML no cambia; por eso las clases se llaman start y end.

7. Espaciado responsive

Como en los contenedores, se puede añadir un breakpoint en medio del nombre: {qué}{dónde}-{breakpoint}-{cuánto}. Es mobile-first: p-2 p-md-5 aplica p-2 en móvil y, a partir de md (768 px), p-5. 

<div class="p-2 p-md-5">…</div>
.relleno-responsive { padding: 0.5rem; }

@media (min-width: 768px) {
  .relleno-responsive { padding: 3rem; }
}

8. Práctica

Ejercicio

  1. Crear una caja con un título y un párrafo, y darle relleno con p-* hasta que el texto respire.
  2. Separar varias cajas seguidas con mb-* en lugar de <br>.
  3. Centrar una caja de 300 px de ancho con mx-auto.
  4. Hacer que el relleno sea pequeño en móvil y grande desde lg.
  5. Escribir el CSS normal equivalente de cada clase usada.

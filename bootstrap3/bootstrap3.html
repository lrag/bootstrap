Bootstrap 5.3 frente a Bootstrap 3

Casi nada de lo que llevamos funciona en Bootstrap 3: las utilidades llegaron en la versión 4, y los modos de color y las variables CSS, en la 5.3.

Base y entorno

Bootstrap 5.3Bootstrap 3
Sin jQueryjQuery obligatorio para el JavaScript
data-bs-theme (modo claro y oscuro)No existe: solo tema claro
Variables CSS --bs-*No existen: valores fijos en el CSS compilado
SassLess (había un port a Sass, pero no era el oficial)
Medidas en remCasi todo en px
bootstrap.rtl.min.cssSin soporte de derecha a izquierda
data-bs-toggle, data-bs-targetdata-toggle, data-target

Contenedores y breakpoints

Bootstrap 5.3Bootstrap 3
6 breakpoints: xs, sm, md, lg, xl, xxl4: xs (<768), sm (≥768), md (≥992), lg (≥1200)
.container-sm, .container-md…No existen: solo .container y .container-fluid

Espaciado: no existe nada

Bootstrap 5.3Bootstrap 3
m-*, p-*, mt-3, px-2, py-2…No hay utilidades de espaciado: CSS propio
mx-auto.center-block (para bloques)
ms-auto / me-auto.pull-right / .pull-left (con float)
start / endSolo left / right

Flexbox: no existe nada

Bootstrap 3 maqueta con float. No hay d-flex, flex-column, justify-content-*, align-items-*, align-self-*, gap-*, flex-wrap, flex-grow-1 ni flex-shrink-0. Centrar en vertical requiere CSS propio.

Tamaños, bordes y sombras

Bootstrap 5.3Bootstrap 3
w-25… w-100, h-*, mw-100No existen
min-vh-100, vh-100No existen
border, border-top, border-primary, border-3No existen
rounded, rounded-circle, rounded-pillSolo para imágenes: .img-rounded, .img-circle
shadow-sm, shadow, shadow-lgNo existen

Visibilidad responsive

Bootstrap 5.3Bootstrap 3
d-none d-md-block.hidden-xs .hidden-sm, o .visible-md-block
d-md-none.visible-xs .visible-sm (con variantes -block, -inline…)
visually-hidden.sr-only
d-print-none / d-print-block.hidden-print / .visible-print-block
invisibleSí existe

Rejilla

Bootstrap 5.3Bootstrap 3
Rejilla con flexboxRejilla con float
.col (columnas automáticas iguales)No existe: siempre hay que poner el número
.col-autoNo existe
.col-6 (xs sin infijo).col-xs-6
Columnas de la misma alturaNo: cada una mide lo que su contenido
offset-md-2.col-md-offset-2
order-1, order-md-first.col-md-push-* / .col-md-pull-*
Gutters g-*, gx-*, gy-*Fijo a 30 px, sin clases para cambiarlo
row-cols-*No existe
AnidadoSí funciona

Texto, color y componentes que han salido de pasada

Bootstrap 5.3Bootstrap 3
text-center, text-success, text-uppercaseSí existen
text-start / text-end, text-md-start.text-left / .text-right, sin versiones responsive
fs-4, fw-boldNo existen
bg-success-subtle, text-bg-success, bg-body-tertiaryNo existen (sí bg-success, bg-primary)
badge text-bg-success.label .label-success (.badge era un contador gris)
btn-outline-primaryNo existe (sí btn-primary, btn-default…)
cardNo existe: .panel, .well, .thumbnail
form-selectNo existe: .form-control también en el <select>
img-fluid.img-responsive

Lo que sí funciona igual

.container, .container-fluid, .row, .btn, .btn-group, .alert, .table, .table-striped, .form-control, text-center, los colores de texto, text-uppercase, invisible y clearfix.
